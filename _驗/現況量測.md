## index.html
```css

  :root { --bg:#f3f4f6; --fg:#1f2937; --red:#9e2a2b; --muted:#6b7280; --card:#fff; }
  @media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { --bg:#111827; --fg:#f3f4f6; --muted:#9ca3af; --card:#1f2937; } }
  html, body { margin:0; height:100%; background:var(--bg); color:var(--fg); font-family:-apple-system, "PingFang TC", "Noto Sans TC", sans-serif; }
  #app { position:fixed; inset:0; width:100%; height:100%; border:0; background:var(--bg); }
  #panel { position:fixed; inset:0; display:flex; align-items:center; justify-content:center; padding:16px; box-sizing:border-box; background:var(--bg); }
  #panel[hidden] { display:none; }
  .card { background:var(--card); border-radius:12px; padding:20px; max-width:420px; width:100%; box-shadow:0 2px 12px rgba(0,0,0,.08); }
  h1 { font-size:18px; margin:0 0 8px; color:var(--red); }
  p { margin:6px 0; line-height:1.6; font-size:15px; }
  .muted { color:var(--muted); font-size:13px; }
  button, a.btn { display:block; width:100%; box-sizing:border-box; margin-top:10px; padding:12px; border-radius:8px; border:0; font-size:16px; text-align:center; text-decoration:none; cursor:pointer; }
  .pri { background:var(--red); color:#fff; }
  .sec { background:transparent; color:var(--fg); border:1px solid var(--muted); }
  /* 【交接32】載入中字樣：純 HTML／CSS，首屏就在，不等 JS；超過 0.6 秒還沒開好才浮出（快的時候不閃）。
     pointer-events:none＝點擊直接穿過，不擋任何操作；站3 開出來（booking-ready）就收掉。本頁其他部分不動。 */
  #loading { position:fixed; z-index:10; left:50%; top:calc(env(safe-area-inset-top, 0px) + 10px); transform:translateX(-50%); pointer-events:none;
             padding:4px 14px; border-radius:999px; background:rgba(17,24,39,.72); color:#fff; font-size:13px; line-height:1.6; white-space:nowrap;
             opacity:0; animation:gyLoading .2s ease-out .6s forwards; }
  #loading[hidden] { display:none; }
  @keyframes gyLoading { to { opacity:1; } }

```

## app/index.html
```css

  :root { --bg:#f3f4f6; --fg:#1f2937; --red:#9e2a2b; --muted:#6b7280; --card:#fff; }
  @media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { --bg:#111827; --fg:#f3f4f6; --muted:#9ca3af; --card:#1f2937; } }
  html, body { margin:0; height:100%; background:var(--bg); color:var(--fg); font-family:-apple-system, "PingFang TC", "Noto Sans TC", sans-serif; }
  #app { position:fixed; inset:0; width:100%; height:100%; border:0; background:var(--bg); }
  /* 【交接32】排版：面板四邊留安全區（瀏海／Home 條）、內容太高時可捲，不截字 */
  #panel { position:fixed; inset:0; display:flex; align-items:center; justify-content:center; box-sizing:border-box; background:var(--bg); overflow-y:auto;
           padding:max(16px, env(safe-area-inset-top, 0px)) max(16px, env(safe-area-inset-right, 0px)) max(16px, env(safe-area-inset-bottom, 0px)) max(16px, env(safe-area-inset-left, 0px)); }
  #panel[hidden] { display:none; }
  .card { background:var(--card); border-radius:12px; padding:20px; max-width:420px; width:100%; box-shadow:0 2px 12px rgba(0,0,0,.08); }
  h1 { font-size:18px; margin:0 0 8px; color:var(--red); }
  p { margin:6px 0; line-height:1.6; font-size:15px; text-wrap:pretty; overflow-wrap:anywhere; }   /* 【交接32】避免最後一行只剩一個字（例：「中…」） */
  .muted { color:var(--muted); font-size:13px; }
  #foot:empty { display:none; }   /* 【交接32】沒紀錄編號時不留空白 */
  button, a.btn { display:block; width:100%; min-height:48px; box-sizing:border-box; margin-top:10px; padding:12px; border-radius:8px; border:0; font:inherit; font-size:16px; line-height:22px; text-align:center; text-decoration:none; cursor:pointer; touch-action:manipulation; }
  .pri { background:var(--red); color:#fff; }
  /* 【交接32】原本 .sec 的外框被 a.btn 的 border:0 蓋掉（權重較高），兩顆次要按鈕看起來像純文字、沒對齊 ⇒ 提高權重 */
  button.sec, a.btn.sec { background:transparent; color:var(--fg); border:1px solid var(--muted); }
  /* 【交接31→32 移植】載入中字樣：純 HTML／CSS，首屏就在，不等 JS；超過 0.6 秒還沒開好才浮出（快的時候不閃）。
     pointer-events:none＝點擊直接穿過，不擋任何操作；站3 開出來（booking-ready）就收掉。 */
  #loading { position:fixed; z-index:10; left:50%; top:calc(env(safe-area-inset-top, 0px) + 10px); transform:translateX(-50%); pointer-events:none;
             padding:4px 14px; border-radius:999px; background:rgba(17,24,39,.72); color:#fff; font-size:13px; line-height:1.6; white-space:nowrap;
             opacity:0; animation:gyLoading .2s ease-out .6s forwards; }
  #loading[hidden] { display:none; }
  @keyframes gyLoading { to { opacity:1; } }

```
